# WM Vendas

Aplicativo PWA de Walquíria Maia para cadastro de produtos, leitura de código de barras/QR Code, vendas, clientes e cobranças.

## Recursos

- Acesso protegido por PIN
- Cadastro e edição completa de produtos
- Fotos privadas dos produtos
- Venda rápida pela câmera
- Controle de estoque, investimento e lucro
- Clientes, vendas parceladas e cobranças pelo WhatsApp
- Instalável no Android, iPhone e computador

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

O frontend usa Next.js e o backend utiliza Supabase Edge Functions, Database e Storage.
